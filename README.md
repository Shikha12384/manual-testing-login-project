# Manual Testing Project - Login Page

This repository contains a complete manual testing project for a sample login functionality.

##  Documents Included
1. **Test Plan** – Overview of objectives, scope, and approach.
2. **Test Cases Sheet** – Detailed test cases with expected and actual results.
3. **Test Summary Report** – Final results and observations after execution.

##  Test Scope
- Login Page validation
- Forgot Password functionality
- Password masking and input field validation

## Tools Used
- Excel for Test Cases & Bug Report
- Word for Test Plan & Summary Report
- Browser: Google Chrome
- Bug Tracking (Manual / JIRA optional)

## 🎯 Purpose
To demonstrate the process of manual testing from planning to reporting for a basic web module.
